# Trekking Management Application V2

MAD-II Project

A web application built using Flask and VueJS to manage trekking activities involving Admin, Trek Staff, and Trekkers.

## Tech Stack

Backend:
- Flask
- SQLite
- Redis
- Celery

Frontend:
- VueJS
- Bootstrap

## Roles

- Admin
- Trek Staff
- Trekker

## Features

- Trek Management
- Trek Booking
- Role Based Access Control
- Trek History
- Reports & CSV Export
- Redis Caching
